# Diriyah OHSS Platform

Occupational health, safety, security and environment management information
system for Diriyah. Single-page React application covering the OHSS workflow
end to end — incident reporting through to executive reporting.

## Requirements

- Node.js 18 or newer
- npm 9 or newer

## Local development

```bash
npm install
npm run dev
```

Vite prints the local URL (normally `http://localhost:5173`). The app runs
fully in the browser against an in-memory dataset, so no database or API
keys are needed to explore it.

## Production build

```bash
npm run build      # typecheck, then bundle to dist/
npm run preview    # serve the built bundle locally
```

`dist/` is a static bundle. CSS is generated by Tailwind at build time and
written into the bundle automatically, so nothing extra is needed to host it.

## Verification

```bash
npm run typecheck         # TypeScript only
npm run validate:routes   # every screen resolves to a route
```

## Deploying to Vercel

1. Push the repository to GitHub.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel auto-detects Vite. The committed `vercel.json` supplies the build
   command, output directory and the single-page rewrite that keeps deep
   links such as `/incidents/register` working on refresh.
4. Deploy. No environment variables are required.

To redeploy after a change, push to the branch Vercel is watching.
